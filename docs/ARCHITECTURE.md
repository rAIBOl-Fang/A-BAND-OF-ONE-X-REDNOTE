# 运行结构

## 目标

本目录是面向电脑端的纯静态网页发布包。用户下载并解压后，直接双击根目录 `index.html` 即可运行，不要求安装依赖、构建项目或连接硬件。

## 运行链路

```text
index.html
  ├── audio-data.js  → 内嵌音频数据
  ├── fx.js          → Canvas 视觉反馈
  └── app.js         → 交互、音色、音区、曲谱和成绩逻辑
                          └── audios/*.mp3 → 本地音频回退
```

## 核心模块

- `index.html`：页面结构、样式和脚本加载顺序。
- `app.js`：自由演奏、跟随模式、曲谱选择、音色切换、音区切换、成绩记录和音频播放调度。
- `fx.js`：演奏时的 Canvas 动效。
- `audio-data.js`：可直接加载的内嵌 MP3 数据；由音频处理流程生成，不应手工编辑。
- `audios/`：与内嵌数据对应的本地 MP3 文件，用于浏览器环境的文件回退。

## 浏览器边界

- 音频上下文只在用户首次点击琴键等手势后创建或恢复，以符合浏览器自动播放策略。
- 成绩通过 `localStorage` 保存在当前浏览器本地，不上传到服务器。
- 发布运行时不调用网络接口、硬件 API 或外部服务。
- 当前交互以鼠标或触控板点击网页琴键为主，不承诺电脑物理键盘映射。

## 目录边界

发布包只保留运行所需代码、音频、截图和公开说明。源采样、转换脚本、赛事过程记录和 Agent 协作文件不属于公开运行时，均不应复制到此目录。
